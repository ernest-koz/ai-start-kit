# fal-images: картинки через агента

Работа в одном окне: ученик описывает задачу словами, ты ведёшь интервью,
собираешь промпт, вызываешь fal.ai API и кладёшь результат в `output/images/`.

## Шаг 1. Интервью (максимум 4 вопроса, только недостающее)

Выясни, чего нет в запросе:

1. **Что на картинке** - субъект и действие (кто/что, что делает, где).
2. **Стиль** - фото, иллюстрация, 3D, плоская графика; если у ученика есть
   референс - попроси файл или ссылку.
3. **Формат и куда пойдёт** - обложка поста (16:9), сторис (9:16), аватар (1:1),
   для сайта (широкая).
4. **Правки или с нуля** - если ученик прислал картинку и просит что-то
   поменять, работай в режиме правок (шаг 4), не генерируй с нуля.

Если всё есть в первом сообщении - не задавай вопросов, работай сразу.

## Шаг 2. Промпт

Собери промпт по структуре и покажи ученику перед генерацией (он утверждает
или правит, это дешевле, чем перегенерация):

```
[субъект и действие], [окружение], [стиль], [свет], [композиция и ракурс], [формат]
```

Промпт уходит в API на английском: переведи собранный промпт сам, покажи
ученику английскую версию рядом с русской. Терминология стилей - по-английски
в любом случае (cinematic lighting, flat vector illustration и т.д.).

## Шаг 3. Генерация (API)

Ключ: `FAL_KEY` из `.env`. Если его нет - остановись и попроси ученика
заполнить `.env` (ключ берётся на fal.ai → Keys).

Быстрая генерация (начни с неё - дешёвая и быстрая):

```sh
curl -s -X POST https://fal.run/fal-ai/flux/schnell \
  -H "Authorization: Key $FAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "ENGLISH_PROMPT", "image_size": "landscape_16_9"}'
```

Качественная (если быстрый результат не устроил по деталям):

```sh
curl -s -X POST https://fal.run/fal-ai/flux/dev \
  -H "Authorization: Key $FAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "ENGLISH_PROMPT", "image_size": "landscape_16_9", "num_inference_steps": 28}'
```

Форматы `image_size`: `square_hd` (аватар), `landscape_16_9`, `portrait_16_9`
(сторис/рилс), `landscape_4_3`, `portrait_4_3`.

В ответе - `images[0].url`. Скачай файл:

```sh
curl -sL -o output/images/<имя>.png "<URL из ответа>"
```

Покажи ученику путь до файла. Каждый следующий вариант - новый запрос с
правками промпта (старые файлы не удаляй, ученик выбирает из всех).

## Шаг 4. Правки готовой картинки

Если ученик прислал свою картинку:

- **Изменить по описанию** (img2img): `fal.run/fal-ai/flux/dev/image-to-image`,
  параметр `image_url` - можно локальный файл, загруженный на любой хостинг
  файлов, или base64 data-URI, сила правки - `strength` 0.3 (легкая) - 0.7 (сильная).
- **Удалить фон**: `fal.run/fal-ai/imageutils/background/remove`, `image_url`.
- **Апскейл**: `fal.run/fal-ai/clarity-upscaler`.

Локальные файлы в API передаются data-URI: `data:image/png;base64,...`
(закодируй файл командой `base64 -w0 файл`). Для больших файлов это медленно -
предупреди ученика, что правка локальной картинки занимает минуту-другую.

## Пайплайны стандартных задач

- **Обложка поста**: интервью → промпт (16:9) → schnell → правки промптом ×2-3 → готово.
- **Иллюстрация к статье**: то же, но уточни, что должно быть на переднем плане
  (перекрытие текстом при вёрстке).
- **Аватар**: square_hd, крупный план, лицо в центре, простой фон.
- **Карточка товара**: товар на нейтральном фоне, мягкий свет; если прислали фото
  товара - режим правок (замена фона).

## Границы

- Люди и лица: генерируй, но предупреждай, что реальные лица получаются
  «похожими на среднее» - для персонального аватара лучше режим правок
  с фото ученика.
- Текст внутри картинок: модели пишут его плохо. Если нужен текст на обложке -
  генерируй фон без текста, текст добавит ученик в редакторе.
- Не обещай лицензионную чистоту генераций для коммерции - ученик решает сам.
