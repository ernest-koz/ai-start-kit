# Стартовый набор: курс «Старт с нейросетями»

> Автор курса: Эрнест Козырев (канал https://t.me/ai_first_start).
> Этот репозиторий - рабочая обвязка для твоего агента OpenCode: правила,
> скиллы и пайплайны уроков. Всё ставит агент - тебе нужен один промпт.

## Установка (делает агент, один раз)

Твои шаги (урок 2):

1. Создай на компьютере папку курса - рабочий каталог, в нём будет жить всё:
   набор, настройки и результаты.
2. Внутри папки создай файл `.env` с двумя ключами (шаблон - `.env.example`):
   `FAL_KEY` - fal.ai → Keys, и `GITHUB_TOKEN` - GitHub → Settings →
   Developer settings → Personal access tokens. Ключ из урока 1 (oc_...) сюда
   не вставляй - это разные ключи для разных сервисов.
3. Открой эту папку в OpenCode и скопируй агенту:

   «вот рабочий каталог курса, в нём .env с ключами - установи и настрой
   всё, что нужно для курса: github.com/ernest-koz/ai-start-kit»

Дальше командная строка не понадобится: инструменты и настройки - работа
агента, в одном окне, обычными словами.

Инструкция агенту (выполняй по шагам, ничего не ставь без одобрения ученика):

1. Скачай архив набора
   (https://github.com/ernest-koz/ai-start-kit/archive/refs/heads/main.zip)
   и распакуй содержимое в рабочий каталог ученика, рядом с его `.env` -
   сам `.env` не перезаписывай и не удаляй.
2. Проверь `.env`: `FAL_KEY` и `GITHUB_TOKEN` заполнены (значения не печатай
   и никуда не отправляй).
3. Проверь инструменты: `bash --version`, `node -v`, `ffmpeg -version`
   (на Windows bash обычно приходит вместе с git). Чего-то нет - предложи
   установку и ставь только после «да» ученика.
4. Создай рабочие папки рилсов: `reels-001` ... `reels-005` в корне каталога,
   в каждой подпапки `input` (клипы) и `output` (рендер) - пустые, ученик
   наполнит их по ходу уроков.
5. Прочитай `AGENTS.md` и `.opencode/skills/` - дальше работай по правилам
   набора.
6. Покажи отчёт: что скачал, что проверил, что предлагаешь дальше.

Первая и регулярная задача после установки: «проверь и настрой своё
окружение» (.opencode/skills/agent-setup) - повторяй раз в неделю.

## Что внутри

```
AGENTS.md              - правила твоего агента (читаются автоматически)
.env.example           - шаблон ключей (fal.ai и GitHub)
.opencode/skills/      - скиллы, OpenCode подхватывает их сам:
  workflow/            - рабочий цикл задач: декомпозиция, план до выполнения, аудит
  agent-setup/         - первая и еженедельная задача: окружение агента
  fal-images/          - урок 2: картинки через fal.ai (интервью, промпт, генерация, правки)
  reels/               - урок 3: рилс из готовых клипов в Remotion
  github-backup/       - страховка: бэкап каталога в приватный репозиторий GitHub
  local-tools/         - локальные инструменты: фон, вырезание, апскейл у папки картинок (без генерации)
output/                - сюда агент складывает результаты (не удаляй)
```

Скиллы уроков самодостаточны: папку `fal-images` или `reels` можно скопировать
в `.opencode/skills/` любого своего проекта (или в `~/.config/opencode/skills/` -
тогда скилл будет во всех проектах сразу). Без остального набора они работают:
сами попросят создать `.env` с ключом и сами создадут нужные папки.

## Уроки

1. Урок 1 (проходится до установки набора): база - OpenCode, аккаунт,
   подписка, ключ, модели.
2. Урок 2: картинки. Генерация и правки через агента + fal.ai.
3. Урок 3: видео. Рилс из твоих клипов: конверт, субтитры, музыка, рендер.

Пайплайны на стандартные задачи уже собраны в скиллы: просто опиши задачу
своими словами, агент сам загрузит нужный скилл и поведёт по шагам.
