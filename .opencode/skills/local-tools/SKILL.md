# local-tools: локальные инструменты ComfyUI (без генерации)

Локальные инструменты для картинок: бесплатно, без лимитов, приватно - файлы
не покидают компьютер. Генерация сюда не входит: новые картинки делаются
через fal.ai (скилл fal-images). fal.ai проще для разовых задач; локальные
инструменты бери, когда задачи серийные (папка файлов) или нужен контроль,
которого нет в API.

## Требования (проверь до установки)

- Диск: 5-6 ГБ свободно (стек ComfyUI + маленькие модели-хелперы).
- Видеокарта не обязательна: ноды работают и на процессоре (медленнее).
  Есть NVIDIA от 6 ГБ - заметно быстрее.
- Моделей генерации нет и не качаем: нужны только маленькие
  модели-инструменты - RMBG-2.0 для фона (около 1 ГБ), SAM для вырезания,
  апскейл 4x-UltraSharp (65 МБ).

## Установка (один раз, минут двадцать)

Простой путь для Windows: официальный **Windows Portable** - скачать 7z со
страницы релизов ComfyUI (github.com/comfyanonymous/ComfyUI/releases),
распаковать, запустить. Внутри уже Python и свежая CUDA-сборка.
Генерационные модели не качаем: студия нужна только для инструментов.
Ручная установка (Linux/macOS) - универсальный вариант:

1. Поставь Git и Python 3.13 (python.org, галочка Add to PATH).
2. В папке, где будут жить инструменты:
   `git clone https://github.com/comfyanonymous/ComfyUI.git && cd ComfyUI`
3. `python -m venv venv && venv\Scripts\activate` (на macOS/Linux -
   `source venv/bin/activate`)
4. `pip install torch torchvision` (для NVIDIA - флаг cu-сборки со страницы
   ComfyUI; для AMD - ROCm-вариант оттуда же)
5. `pip install -r requirements.txt`
6. Запуск: `python main.py` - интерфейс на http://127.0.0.1:8188.
   Ярлык запуска сделай один раз и пользуйся им.
7. Нода инструментов: через ComfyUI-Manager поставь **ComfyUI-RMBG**
   (автор 1038lab) - один пакет закрывает и удаление фона (RMBG-2.0),
   и вырезание объектов (SAM/SAM2/SAM3).

## Рабочие флоу (агент помогает собрать, ошибки разбирает по тексту)

1. **Удаление фона у папки картинок** (батч - десятки файлов за раз,
   онлайн-сервисы берут по одному): Load Image → Remove Background (RMBG) →
   Save Image. Модель RMBG-2.0 скачивается автоматически при первом запуске
   в `ComfyUI/models/RMBG/` (вручную - с HuggingFace 1038lab/RMBG-2.0 в
   `models/RMBG/RMBG-2.0`).
2. **Вырезание объекта** с аккуратной маской по краям: Load Image → нода
   SAM2/SAM3 (клик или текстовый промпт по объекту) → Save. Модели тоже
   скачиваются автоматически при первом использовании.
3. **Апскейл 2x-4x** без потери деталей: Load Image → Upscale Model
   (4x-UltraSharp) → Save.

Модели скачиваются автоматически при первом использовании нужной ноды:
фон/вырезание - в `ComfyUI/models/RMBG/`, апскейл - в
`ComfyUI/models/upscale_models`. Скачанные вручную модели кладутся в те же
папки (например, `models/RMBG/RMBG-2.0`). Ошибка «модель не в той папке» -
самая частая; ссылки на конкретные модели давай по запросу.

Скачанные флоу-файлы (JSON) открываются перетаскиванием в окно ComfyUI.
Если ученик присылает скриншот ошибки - читай текст ошибки и правь шаги:
90% проблем это «модель не в той папке» и «не хватает видеопамяти»
(лечится перезапуском с флагом `--lowvram`).

## Маттинг: RMBG-2.0 по умолчанию

Удаление фона - модель RMBG-2.0 от BRIA: топ по качеству краёв. Курс для
личного использования, и её лицензия (некоммерческое использование) это
покрывает. Простые онлайн-утилиты и классический rembg/u2net заметно слабее.
Если работы уходят в коммерцию (карточки товаров, реклама) - два пути: API
fal (`briaai/remove-background`, коммерческое использование включено в цену)
или BiRefNet-HR - она в той же ноде (модель из списка, веса с HuggingFace
1038lab/BiRefNet_HR, открытая лицензия).

## fal-нода внутри ComfyUI (когда студия уже стоит)

Плюс ноды - не цена и не качество моделей: они те же, что у прямого API.
Плюсы в другом:

- цепочки: результат fal сразу входит в локальные ноды (fal-генерация →
  локальный апскейл → фон → сохранение) без ручных скачиваний;
- флоу сохраняется JSON-файлом и прогоняется сколько нужно - повторяемость;
- батчи по папке решаются графом, без скриптов;
- контроль расходов: `[spend_guard]` в config.ini ноды - при прямом API
  траты смотрят только в дашборде fal.

Нода: **ComfyUI-fal-API** (gokayfem). Ключ FAL_KEY тот же из `.env` -
вписать в config.ini ноды (`custom_nodes/ComfyUI-fal-API/config.ini`,
секция `[API]`). VPN для загрузки файлов нужен так же, как прямому API.
Разовые задачи делай прямым API (скилл fal-images) - нода раскрывается
на серийных графах и батчах.

## Границы

- Генерация картинок - только через fal.ai (скилл fal-images). Локальная
  генерация в этот скилл не входит. Захочется позже - чекпойнт кладётся
  одним файлом в `models/checkpoints`, переустановка не нужна.
- Обновления ComfyUI не делай по своей инициативе: рабочую студию не чиним,
  пока она работает.
