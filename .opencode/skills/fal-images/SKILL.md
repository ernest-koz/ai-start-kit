# fal-images: картинки через агента

Работа в одном окне: ученик описывает задачу словами, ты ведёшь интервью,
собираешь промпт, вызываешь fal.ai API и кладёшь результат в `output/images/`.

## Шаг 1. Интервью (максимум 3 вопроса, только недостающее)

Выясни, чего нет в запросе:

1. **Что на картинке** - субъект и действие (кто/что, что делает, где).
2. **Стиль** - фото, иллюстрация, 3D, плоская графика; если у ученика есть
   референс - попроси файл или ссылку.
3. **Формат и куда пойдёт** - обложка/карусель для ленты (4:5), сторис/рилс
   (9:16), аватар (1:1), широкий баннер (16:9).
4. **Правки или с нуля** - если ученик прислал картинку и просит что-то
   поменять, работай в режиме правок (шаг 4), не генерируй с нуля.

Если всё есть в первом сообщении - не задавай вопросов, работай сразу.

## Шаг 2. Промпт

Собери промпт по структуре и покажи ученику перед генерацией (он утверждает
или правит, это дешевле, чем перегенерация):

```
[субъект и действие], [окружение], [стиль], [свет], [композиция и ракурс], [формат]
```

Промпт уходит в API на английском: переведи собранный промпт сам, покажи
ученику английскую версию рядом с русской. Терминология стилей - по-английски
в любом случае (cinematic lighting, flat vector illustration и т.д.).

## Шаг 3. Генерация (API)

Ключ: `FAL_KEY` из файла `.env` в корне проекта. Если `.env` нет - попроси
ученика создать его со строкой `FAL_KEY=` и вписать ключ с сайта fal.ai →
Keys самостоятельно. Значение ключа не печатай в ответах и не сохраняй
в output/.

Все команды скилла - bash (на Windows - Git Bash, ставится вместе с git).

Перед запросами загрузи переменные из `.env` в шелл - значение ключа при
этом не печатается и в текст команды не подставляется:

```sh
set -a; . ./.env; set +a
[ -n "$FAL_KEY" ] || { echo "FAL_KEY пуст - заполни .env"; }
```

Каталог моделей у fal меняется часто. Не бери список моделей из веб-страниц
или llms.txt - они устаревают. Актуальный список даёт API каталога (без ключа):

```sh
curl -s "https://fal.ai/api/models?categories=text-to-image&page=1" -H "Accept: application/json"
curl -s "https://fal.ai/api/models?keywords=nano-banana&page=1" -H "Accept: application/json"
```

В ответе `items[]`: `id`, `title`, `category`. Эндпоинт вызова модели -
`https://fal.run/<id>`. Цену смотри на странице модели
(`fal.ai/models/<id>/api`) - цены меняются.

Генерация из текста - основная модель: `openai/gpt-image-2.6/sunburst/text-to-image`
(GPT Image 2.6 Sunburst, лучшая на сейчас). Биллинг по юнитам: цена юнита $1,
но картинка списывается долями юнита - на реальных прогонах 0.2-0.3 юнита
(около $0.2-0.3) в зависимости от размера и параметра `quality`. Пример под
ленту Instagram:

```sh
curl -s -X POST https://fal.run/openai/gpt-image-2.6/sunburst/text-to-image \
  -H "Authorization: Key $FAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "ENGLISH_PROMPT", "image_size": {"width": 1152, "height": 1440}, "output_format": "png"}'
```

Бюджетная альтернатива - Seedream v5 Pro, проверена на наших задачах (около
$0.07 за картинку): `fal.run/bytedance/seedream/v5/pro/text-to-image`,
параметр размера `custom_size`, размер кратен 16: лента 4:5 - 1152x1440,
сторис/рилс 9:16 - 1024x1792, аватар 1:1 - 1024x1024, баннер 16:9 - 1280x720.
Seedream понимает прямые «no X» в промпте. Если основная модель недоступна
или исчезла из каталога - не чини id вручную: возьми свежую лучшую из
актуального каталога выше. Для правок готовых фото - Nano Banana (шаг 4).

Один запрос - один вариант. Несколько вариантов подряд не делай: ученик
смотрит результат и говорит, что поменять - следующий запрос идёт с правкой
промпта. Старые файлы не удаляй - история выбора.

В ответе - `images[0].url`. Скачай файл:

```sh
mkdir -p output/images && curl -sL -o output/images/<имя>.png "<URL из ответа>"
```

Покажи ученику путь до файла. Каждый следующий вариант - новый запрос с
правками промпта (старые файлы не удаляй, ученик выбирает из всех).

Сеть: загрузка файлов на fal (CDN `v3.fal.media`) закрыта для российских
IP-адресов - если загрузка исходников не проходит, нужен VPN. Сам API
(`fal.run`) и генерация из текста работают без VPN (проверено 14.10.2026).

## Шаг 4. Правки готовой картинки

Если ученик прислал свою картинку:

- **Изменить по описанию** (основная модель правок): `fal.run/google/nano-banana-2.1/edit`.
  Промпт с инструкцией правки плюс ссылка на картинку (загруженный на хостинг
  файл или base64 data-URI). NB2.1 сильна именно в правках по инструкции:
  убрать фон, сменить окружение, поставить человека на новый фон. Биллинг
  по юнитам, как у Sunburst. Точную схему параметров сверь на странице
  модели - у Gemini-семейства она обновляется чаще других.
- **Удалить фон**: `fal.run/fal-ai/imageutils/rembg`, параметр `image_url`.
- **Апскейл**: `fal.run/fal-ai/clarity-upscaler`.

Локальные файлы в API передаются data-URI: `data:image/png;base64,...`
(закодируй файл командой `base64 -w0 файл`; на macOS флага `-w` нет - там
`base64 -i файл | tr -d '\n'`). Для больших файлов это медленно -
предупреди ученика, что правка локальной картинки занимает минуту-другую.

## Пайплайны стандартных задач

- **Реставрация старого фото** (проверено на семейном архиве, 09.11.2026):
  1. Геометрия локально (бесплатно): вырезать отпечаток из кадра, выпрямить
     перспективу, повернуть (OpenCV). Превью геометрии - на подтверждение.
  2. Реставрация: `fal.run/google/nano-banana-2.1/edit`, промпт описывает
     дефекты («убери царапины, пятна и шум, вытяни детали и лица, приведи
     к нейтральному чёрно-белому, не меняй черты лица и композицию»).
     Около $0.10 за прогон. Слово «vintage» в промпт не писать - модель
     добавляет плёночное зерно. Исходник не трогать, итог положить рядом.
  3. Удаление предмета из кадра - той же моделью, отдельным проходом.
  4. Цвет для ч/б: `fal.run/bria/fibo-edit/colorize` ($0.04).
  Отклонённые пути (проверены, хуже): `topaz/restore/image` - теряет черты
  лица и дороже; `fal-ai/nafnet/denoise` - сглаживает глаза и мелкие детали;
  `fal-ai/image-editing/face-enhancement` - меняет внешность и режет
  разрешение. Не предлагать их ученику.
- **Обложка поста**: интервью → промпт (4:5, генерация из шага 3) → правки
  промптом ×2-3 → готово.
- **Карусель (серия слайдов в одном стиле)**: первый слайд - как обложку; потом
  новые вызовы с теми же словами стиля/света в промпте и изменённой композицией
  (2-3 слайда). Текст на слайдах - не в генерации: ровные надписи добавляются
  поверх готовых фонов.
- **Иллюстрация к статье**: то же, но уточни, что должно быть на переднем плане
  (перекрытие текстом при вёрстке).
- **Аватар**: square_hd, крупный план, лицо в центре, простой фон.
- **Карточка товара**: товар на нейтральном фоне, мягкий свет; если прислали фото
  товара - режим правок (замена фона).

## Границы

- Люди и лица: генерируй, но предупреждай, что реальные лица получаются
  «похожими на среднее» - для персонального аватара лучше режим правок
  с фото ученика.
- Текст внутри картинок: модели пишут его плохо. Если нужен текст на обложке -
  генерируй фон без текста, текст добавит ученик в редакторе.
- Не обещай лицензионную чистоту генераций для коммерции - ученик решает сам.
